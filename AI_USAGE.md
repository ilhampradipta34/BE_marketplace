# Penggunaan AI

## Alat yang digunakan

- OpenAI Codex di IDE membantu merancang dan mengubah backend Laravel, frontend Next.js, dokumentasi, serta merapikan kode berdasarkan brief dan umpan balik.
- Dokumentasi resmi Next.js, Auth.js, dan TanStack Query ditelusuri untuk memastikan pola integrasi frontend. PowerShell, Composer, Artisan, Pest, dan npm digunakan sebagai alat kerja/verifikasi; alat terminal tersebut bukan AI.

## Prompt utama

Berikut empat prompt dari percakapan pengerjaan, disalin apa adanya:

1. `untuk bagian difolder api controller pake begin db transaction dan roolbak serta trycatch dan juga rapikan ya`
2. `untuk singaktan $v dan $r tolong diperjelas ya itu apa`
3. `di folder frontend install next js dan pake tansatck cquery untuk api management, authnya pake next auth buat ui yg elegan dan modern warna hijau/tale dominan kemduian diasih lazy load lalu pake typescript jadi bisa bikin folder type untuk menginitialize type data`
4. `yang dibackend consume api semuanya dan tampilkan di frontend semuanya`

## Bagian yang dibantu AI dan kontribusi pengembang

Pengembang memberikan kebutuhan fitur, aturan bisnis, arahan struktur folder, dan umpan balik melalui prompt. Dalam sesi pengerjaan yang terdokumentasi ini, Codex membantu menulis atau mengubah controller, request, resource, model, migrasi, factory, seeder, route, test, konfigurasi, API client, hook, komponen UI, dan dokumentasi. Saya tidak mengklaim bahwa perubahan kode tersebut ditulis sendiri tanpa bantuan AI.

Perintah terminal digunakan untuk memasang dependency dan memeriksa aplikasi. Pengembang tetap bertanggung jawab meninjau perubahan, memahami kode, menguji hasil di lingkungannya, dan hanya menyatakan sebagai kontribusi manual bagian yang memang ia tulis atau ubah sendiri di luar bantuan AI.
